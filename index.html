Documentación

Cómo usar PAES Manager

1

Instalar Python y dependencias

Necesitas Python 3.8+ instalado. Luego instala las dependencias:

pip install PyMuPDF reportlab requests
2

Descargar las pruebas

Ejecuta el script de descarga. Las pruebas se guardan en pruebas_paes/:

python descargar_paes.py
3

Generar un ensayo mezclado

Genera un ensayo rápido con historia y matemáticas, 10 páginas de cada una:

python mezclar_paes.py --rapido historia m1 --paginas 10 --titulo "Ensayo 1"
4

Modo interactivo

Sin argumentos, el script abre un menú interactivo:

python mezclar_paes.py
5

Reiniciar preguntas usadas

Si quieres que el sistema olvide qué páginas usó:

python mezclar_paes.py --reset
6

Códigos de prueba disponibles

Usa estos códigos con el flag --rapido seguido del año:

historia_2026 · m1_2026 · m2_2026 · lectora_2026 biologia_2026 · quimica_2026 · fisica_2026 · tp_2026 # También por año: historia_2025 · lectora_2024 · m1_2023 ...
