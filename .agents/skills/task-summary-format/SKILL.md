# 📋 Skill: Formato de Resumen de Tarea / Bitácora

Este skill establece el formato y estructura obligatoria para resumir y registrar la ejecución de tareas o instrucciones solicitadas por el usuario.

---

### [AAAA-MM-DD] Título o Tema de la Instrucción
- **Problema / Requerimiento**: Breve descripción de lo que me solicitaste resolver.
- **Archivos y Solución Técnica**: Lista de archivos creados/modificados y cambios explicados.
- **Verificación / Despliegue**: Estado final (pruebas ejecutadas, commits en Git, despliegues en Vercel, etc.).
